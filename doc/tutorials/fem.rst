Implicit Solver (FEM)
=====================

Tutorial 1 gives an overview of the finite element discretization used by the implicit solver.
Tutorials 2 and 3 show how to set up simulations via configuration files and via Python scripting, respectively.
In tutorial 4, the implicit solver is compared to the explicit solver.
Tutorials 5 to 7 validate the implicit solver against literature results, analytical solutions for in-plane shear and inertia,
and the Reynolds equation. The final tutorial collects further simulation examples.
